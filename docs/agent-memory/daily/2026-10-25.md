## Changes
- PR #65 (`97dd71c`): root cause of the invisible opt-in block found and fixed.
  - The extension had no tsconfig.json of its own, so the Shopify CLI bundled it with the app's root tsconfig and compiled JSX with react/jsx-runtime (visible in dist/*.metafile.json inputs).
  - Preact's render() silently ignores React elements. That explains recete-18 (the useEffect never ran: the component was never mounted) and recete-19 (eligible, render called, nothing drawn).
  - Fix: tsconfig.check.json → tsconfig.json (jsxImportSource preact). The bundle now uses preact/jsx-runtime.
  - app/lib/extensionsJsx.test.ts guards every UI extension with JSX.
  - manifest.json (written by `shopify app build`) is gitignored.
