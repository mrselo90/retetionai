## Decisions

- Shopify token ownership: each shop's expiring offline token chain has one owner (`integrations.auth_data.token_owner`). `shell` = the Shopify app refreshes, and the API and workers ask `POST /internal/offline-token`. `api` = the API refreshes (dashboard OAuth, /verify-session). Shopify retires tokens when two places acquire or refresh, so never refresh a shell chain from the API.
- `SHOPIFY_SHELL_INTERNAL_URL` (not `SHOPIFY_SHELL_URL`) for the token lookup. Setting `SHOPIFY_SHELL_URL` also turns on shell plan lookup and usage billing; that is a separate decision (see Open Items).
